# Definición de Hecho (DoD)

Una tarea se considera terminada cuando cumple todo lo siguiente:

- Compila sin errores ni advertencias.
- Cumple los criterios de aceptación (Gherkin) de su Issue.
- Tiene pruebas unitarias en verde cuando aplica.
- El Pull Request fue aprobado por otro integrante.
- La documentación está actualizada.
- El Issue está cerrado y movido a Finalizado en el tablero.
